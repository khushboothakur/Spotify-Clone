# Spotify-Clone
A Spotify Clone Project built for learning and practicing web development.

Spotify Clone 🎵
This is a simple Spotify UI Clone built using HTML and CSS.

Features
Spotify-inspired user interface
Responsive design using media queries
Clean layout similar to the Spotify music app
Tech Stack
HTML
CSS
Note
This project focuses only on the frontend UI design.
Music playback and backend functionality are not implemented yet.

Purpose
This project was created to practice frontend development and responsive web design.
